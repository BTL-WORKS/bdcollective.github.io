## Repo

Bu depo btlworx.com sitesinin canlı kaynak kodudur. GitHub Pages üzerinde barındırılır.

- `index.html` — ana sayfa
- Alt klasörler — landing sayfalar, blog yazıları, pillar rehberler
- `_redirects` — Cloudflare/Netlify uyumu için (GitHub Pages okumuyor)
- `_headers` — HTTP header konfigürasyonu
- `CNAME` — domain bağlantısı (btlworx.com)
- `.nojekyll` — GitHub Pages Jekyll build'i devre dışı
- `sitemap.xml` — SEO sitemap
- `robots.txt` — bot erişim kuralları
- `feed.xml` — RSS feed

## Deploy

Her `main` branch push'ı GitHub Pages tarafından otomatik deploy edilir.

**Deploy süresi:** 1-3 dakika.
